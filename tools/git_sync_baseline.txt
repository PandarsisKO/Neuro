# excludes from Git/GitHub. The largest is 1,369,449,027 bytes:

#     VIDEOS/Screen Recording 2026-09-03 at 12.08.20 PM.mov   1.37 GB
#     (plus blobs of 956 MB, 441 MB, 302 MB and 156 MB)
#
# GitHub's hard limit is 100 MB per file, so pushing any ref whose history reaches those blobs fails
# with `RPC failed; HTTP 500` -- observed directly when pushing the two branches below. At some point
# the history was re-created without that media and the clean lineage became origin/main; the old
# lineage was never published and cannot be without a history rewrite (git-filter-repo) or Git LFS.
#
# Publishing them is also forbidden on its own terms: HANDOFF.md says "Do not add VIDEOS/, data/ or
# _to_delete/ to a snapshot." Succeeding would be as wrong as failing.
#
# REMEDIATION, when someone authorizes it: rewrite the legacy lineage with git-filter-repo to strip
# blobs over 100 MB, or migrate them to Git LFS, then publish the rewritten refs under new names.
# That is a separate mission -- it rewrites history and needs Kyle's explicit approval. Until then the
# 2026-09-22 repair's finding stands: this material is backed up on the Mac only.
